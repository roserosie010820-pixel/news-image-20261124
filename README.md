A program that draws one image summing up the world news of Tuesday 24 November 2026: a newspaper front page with six stories, rendered with a software rasterizer and a hand-built 5x7 bitmap font, then encoded as PNG. Node 22, standard library only, no network, deterministic — two runs write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
